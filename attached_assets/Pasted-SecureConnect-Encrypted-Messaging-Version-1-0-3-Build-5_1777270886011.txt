ENCRYPTION DECLARATION
The app uses standard end-to-end encryption (Signal Protocol: X3DH key
agreement + Double Ratchet, XSalsa20-Poly1305, Curve25519, HKDF-SHA256)
and HTTPS/TLS for transport. ITSAppUsesNonExemptEncryption is set to
false because the app qualifies for the Note 4 exemption (standard
encryption used to protect user content).
