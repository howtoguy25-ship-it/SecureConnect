PERMANENT REQUIREMENT — APPLE REVIEWER DEMO ACCESS MUST WORK
End-to-End Verification Before Every App Store Submission

Before submitting any build to App Store Connect, the Apple reviewer
demo path MUST be verified working in BOTH places below. If either
side is broken, the submission WILL be rejected and the review cycle
restarts (3–7 days lost per rejection).

────────────────────────────────────────────────────────────────────
PART A — App Store Connect "App Review Information" (Developer Side)
────────────────────────────────────────────────────────────────────

In App Store Connect → My Apps → [this app] → [version] → 
App Review Information, the following MUST be filled in and current
for every submission:

Sign-in required:           YES
Demo account phone number:  555-1234567
Demo account OTP code:      (whatever code the bypass accepts —
                             document the exact value here)
Contact information:        valid name, email, phone the reviewer
                             can actually reach
Notes for reviewer:         Must explain:
                              - This app uses phone + OTP only
                              - Enter 555-1234567 as the phone number
                              - Enter [OTP code] when prompted
                              - The account has full VIP access so 
                                all paid features can be evaluated
                              - Any non-obvious flows (where to find
                                the ad-supported screens, where VIP
                                features unlock, etc.)

Rules:
- Do NOT leave "Sign-in required" set to NO if the app gates content
  behind login — reviewer will fail at the welcome screen and reject.
- Do NOT submit with stale demo credentials from a prior build.
- Do NOT rely on the reviewer to "figure it out" — spell out the 
  exact phone number and OTP code in the notes field.
- If the demo OTP code ever changes in routes.ts, update the App 
  Store Connect notes BEFORE submitting the build that contains the
  change.
- Keep the contact phone/email monitored during review — Apple will
  call/email if the demo account fails and you have ~24h to respond
  before auto-rejection.
