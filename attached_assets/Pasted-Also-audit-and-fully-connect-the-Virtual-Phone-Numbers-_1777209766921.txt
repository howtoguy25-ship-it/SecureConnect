- Message plaintext must never be stored in the database.
- Encrypt message once with normal chat encryption.

- Receiver must be valid.
- Block spoofing another virtual number.
- Block users from querying virtual numbers they do not own.

7. Add UI checks:
- Show which virtual number is being used before sending.

8. Run full tests:
