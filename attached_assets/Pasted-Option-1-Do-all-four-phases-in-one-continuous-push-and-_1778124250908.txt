For disappearing messages:
Use secure hybrid expiry.

Requirements:
- Messages expire locally on both devices.
- Also store encrypted expiry metadata server-side for sync consistency across devices.
- Server must NEVER store plaintext.
- Server only knows:
  - encrypted payload
  - expiresAt timestamp
  - deletion/expiry event metadata
- When expiry time is reached:
  - message auto-removes locally
  - sync secure delete/expiry event to participants

- Expired messages must not appear in:
  - notifications
  - search
  - previews
  - pinned messages
  - forwarded content
- Handle offline users:

- Add cleanup jobs for expired encrypted payloads server-side where supported.
- Preserve end-to-end encryption and never expose plaintext during expiry processing.
