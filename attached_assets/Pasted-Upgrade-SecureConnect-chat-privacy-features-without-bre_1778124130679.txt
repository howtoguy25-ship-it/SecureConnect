CHAT LONG-PRESS MESSAGE MENU:
When a user holds/long-presses any message bubble, show a modern floating action menu above/beside the message with these options:

1. Reply
2. Forward
3. Copy
4. Select
5. Pin
6. Info
7. Delete

The menu must:
- Match the screenshot style: rounded white/blur card, modern icons, smooth scale/fade animation.
- Work for both sent and received messages.
- Dismiss when tapping outside.
- Support dark mode if the app has it.
- Use haptic feedback on long press.

REPLY FEATURE:
- When Reply is tapped, show a modern reply preview bar above the message input.
- Display the original sender name and a short preview of the replied message.
- Include an X button to cancel reply.
- When the reply is sent, attach reply metadata to the encrypted message.
- In the chat bubble, show a compact quoted reply preview.
- Tapping the quoted preview should scroll/highlight the original message if still available.

FORWARD FEATURE:
- When Forward is tapped, open a contact/chat picker.
- Allow selecting one or multiple chats/users.
- Forward the selected encrypted message safely.
- Do not expose plaintext to the server.
- Forwarded messages should show a small “Forwarded” label.
- Preserve media/message type where supported.
- Show success/failure feedback.

COPY FEATURE:
- Copy decrypted message text to clipboard only on the user’s device.
- If the message is media-only, show “Nothing to copy” or copy caption if available.
- Show a small toast: “Message copied”.

SELECT FEATURE:
- Enter multi-select mode.
- Show check circles beside messages.
- Allow selecting multiple messages.
- Add a bottom action bar with delete, forward, and cancel.
- Keep the UI smooth and modern.

PIN FEATURE:
- Pin selected message in the current chat.
- Display pinned message preview at the top of the chat.
- Allow tapping pinned preview to jump to message.

MESSAGE INFO FEATURE:
- Open a message info screen/bottom sheet.

  - Sender

DELETE FEATURE:
When Delete is tapped, show a modern confirmation sheet with two options:

1. Delete for me
2. Delete for me and the other user

Rules:
- “Delete for me” removes/hides the message only locally for the current user.
- “Delete for me and the other user” sends a secure deletion event to the other participant and replaces the message with “This message was deleted”.
- Only allow delete-for-everyone within a sensible allowed time window if the backend/app requires it.
- Handle offline state by queueing deletion events.
- Add confirmation text so users understand the action.
- Make delete icon/text red.

READ RECEIPTS:
Add a real Read Receipts toggle in Settings > Privacy.

When ON:
- Send and display read receipts.
- Show read status/timestamps for messages.
- Message Info should include read time.

When OFF:
- Do not send read receipts.
- Do not show other users’ read receipts to this user.
- Respect privacy both ways.
- Persist this setting per user in the database.
- Sync setting across devices if the app supports multi-device.

TYPING INDICATORS:
Add a real Typing Indicators toggle in Settings > Privacy.

When ON:
- When a user is typing, send real-time typing status to the other user.
- Inside the chat, show a modern “typing…” indicator where messages appear.
- Outside the chat, in the chat list, show “typing…” under the user’s name in real time.
- Stop typing indicator after a short timeout or when message is sent.

When OFF:
- Do not send typing events.
- Do not display typing events from others.
- Persist the setting per user.
