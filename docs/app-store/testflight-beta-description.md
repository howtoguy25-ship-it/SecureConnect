## Beta App Description (short version — recommended)

**Pryvo — Private Messenger (Beta)**

Welcome to the Pryvo beta. You're testing a fully end-to-end encrypted messenger with private voice and video calls, virtual phone numbers, disappearing messages, and a hidden locker for the stuff you don't want anyone else seeing.

**What to try in this build:**
• Send and receive encrypted text, photos, and voice notes
• Place voice and video calls — listen for the new ringtones and ringback tones
• Missed a call? Look for the new "Missed call" message right inside the chat — tap it to call back
• Get your own virtual phone number from Settings
• Set a disappearing-message timer on any chat
• Set up the Hidden Locker with a PIN

**Sign in:** Phone number + SMS code only. No email, no Apple/Google login.

This is a beta, so a few rough edges are expected. Please use **Send Feedback** above for anything that crashes, looks wrong, or feels slow. Your feedback shapes the next build.

No payments required during the beta — Pryvo Plus features are unlocked for testers.

Thanks for testing Pryvo.

## What to Test (separate field in TestFlight)

Focus your testing on these areas:

1. **Calling** — Place audio and video calls. Check ringtones play on incoming, ringback plays on outgoing, audio is clear, speakerphone works, and missed calls show up in the chat.
2. **Encrypted messaging** — Send text, photos, voice notes. Try disappearing-message timers.
3. **Virtual numbers** — Claim a number in Settings, send and receive SMS to it.
4. **Hidden Locker** — Set a PIN, save photos and notes inside, lock and unlock.
5. **Status feed** — Post a status, view others, mute someone.
6. **Live location** — Share live location inside a chat.
